## Features

- 🎮 Three difficulty levels (Easy, Medium, Hard)
- ⏱️ Timer to track your solving time
- 💡 Hint system when you're stuck
- ↶ Undo functionality
- 📝 Memo mode for notes
- 🌙 Dark mode support
- 📊 Statistics tracking
- ✓ Solution validation

## How to Play

1. Click on a cell to select it
2. Use the number pad or keyboard (1-9) to enter numbers
3. Use arrow keys to navigate between cells
4. Press 'M' or click the memo toggle to switch to memo mode for notes
5. Use the hint button if you get stuck (adds a penalty to your move count)
6. Click "Check" to validate your solution

## Running Locally

Simply open `index.html` in your web browser - no build process required!
