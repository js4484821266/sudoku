How to Play Sudoku

Rules:

  • Fill the 9×9 grid with numbers 1-9
  • Each row must contain all digits 1-9
  • Each column must contain all digits 1-9
  • Each 3×3 box must contain all digits 1-9

Controls:

  • Click a cell to select it
  • Number keys (1-9) to enter numbers
  • Backspace/Delete to clear a cell
  • Arrow keys to navigate cells
  • Memo Mode to add small notes

Features:

  • 🎯 Three difficulty levels
  • ⏱️ Track your solving time
  • 💡 Get hints when stuck
  • ↶ Undo your moves
  • 🌙 Dark mode support
